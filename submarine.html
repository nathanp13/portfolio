Submarine RADIO FRANCE

MAQUETTAGE ET GRAPHISME D'UNE APPLICATION RADIO FRANCE DEDIEE A LA RECHERCHE DE PODCAST

Concept : Lors de mon stage chez radio france, j'ai eu l'occasion de faire la maquette totale d'une application près à voir le jour qui n'avait pas encore d'interface graphique : Submarine. Mes maquettes ont été validées et seront utilisées lors du déploiement de l'application.

Compétences : Maquettage, UX design, Réflexion

Outils : Figma pour toute la partie maquette, Pinterest pour inspiration, API Submarine pour les tests
